## OctoAcme Project Management Overview

OctoAcme runs projects following a structured, iterative approach that emphasizes customer value, clear ownership, and data-driven decisions.

### Core Principles

- **Customer-first**: Prioritize customer value and usability
- **Iterative delivery**: Deliver small, testable increments
- **Clear ownership**: Each project has named Project Manager (PM) and Product Lead roles
- **Data-informed**: Measure impact and iterate based on evidence
- **Psychological safety**: Encourage feedback and learning

### Lifecycle Overview

The OctoAcme project lifecycle consists of five interconnected phases:

1. **Initiation** — Validate business need, define success metrics, confirm stakeholder alignment, and make a go/no-go decision
2. **Planning** — Break work into shippable increments, estimate scope, identify dependencies, and establish a Definition of Done
3. **Execution** — Build and test features iteratively with daily standups, PR reviews, and regular quality checks
4. **Release** — Deploy to production following a checklist, verify in staging, and communicate with stakeholders
5. **Retrospective** — Capture learnings, identify improvements, and feed insights back into processes

### Key Roles

| Role | Responsibilities |
|------|------------------|
| **Project Manager (PM)** | Coordinates delivery, manages schedules, risks, and communications |
| **Product Manager (PdM)** | Defines outcomes, prioritizes backlog, and measures success |
| **Developers** | Implement features, collaborate on design, and ensure quality |
| **QA/Testing** | Validate quality and acceptance criteria |
| **Stakeholders** | Provide inputs, approvals, and strategic guidance |

### Key Artifacts

| Artifact | Purpose | Owner |
|----------|---------|-------|
| Project Charter / One-pager | Define problem, goals, success metrics | Product Lead, PM |
| Backlog | Prioritized list of work items | Product Manager |
| Risk Register | Track risks, mitigations, status | PM |
| Release Notes | Communicate changes to stakeholders | PM, Product Lead |
| Retrospective Notes | Capture learnings and action items | PM |

### Communication Cadence

- **Daily standups** (15 min) — Focus on progress, blockers, dependencies
- **Weekly PM + PdM sync** — Alignment on priorities and risks
- **Twice-weekly team standups** — Delivery updates and coordination
- **Weekly risk review** — Risk register updates and escalations
- **Monthly stakeholder updates** — Progress, metrics, and forecasts
- **Retrospectives** — After each sprint or milestone
